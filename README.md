# 고물상 타이쿤: ASMR 자원순환 시뮬레이터

모바일 세로 모드 2D 도트 ASMR · 물리 기반 수거 및 가공 시뮬레이션 프로토타입입니다.

## 포함 파일
- `index.html`: 별도 빌드 도구 없이 브라우저에서 바로 실행 가능한 1~3단계 통합 프로토타입
- `junkyard_game_gdd.md`: 전체 게임 기획서 (GDD)
- `push.bat`: Git 저장소 연결 후 더블클릭으로 자동 커밋/푸시하는 편의 스크립트

## 실행 방법
`index.html` 파일을 Chrome, Edge, Safari 등 모바일/PC 브라우저로 열면 즉시 플레이할 수 있습니다.
